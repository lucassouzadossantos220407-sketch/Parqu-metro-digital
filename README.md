# 🚗 ParkSystem — Simulador de Parquímetro

O ParkSystem é um projeto que desenvolvi durante meus estudos de JavaScript, com o objetivo de praticar Programação Orientada a Objetos (POO) e manipulação do DOM.

A aplicação simula um parquímetro digital: o usuário informa quanto deseja pagar e o sistema calcula o tempo de estacionamento correspondente e o troco, caso exista.

## 💻 Funcionalidades

- Inserção do valor do pagamento.
- Cálculo automático do tempo de estacionamento.
- Cálculo e exibição do troco.
- Validação de valores abaixo do mínimo permitido.
- Apresentação dos resultados na tela.

## 💰 Tabela de tarifas

| Valor | Tempo de estacionamento |
|---|---|
| R$ 1,00 | 30 minutos |
| R$ 1,75 | 60 minutos |
| R$ 3,00 | 120 minutos |
